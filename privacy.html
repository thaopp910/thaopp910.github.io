Privacy policy

Content Hub · effective 12 October 2026

Content Hub is a private tool used only by its owner. This page explains what it does with data from Google APIs.

Data it accesses

  • Google Analytics, read-only scope analytics.readonly: aggregated reports such as sessions, traffic sources and page views.
  • Google Search Console, read-only scope webmasters.readonly: aggregated clicks, impressions and search queries.

It cannot change, delete or create anything in these accounts.

How the data is used

The reports are used only to answer the owner's own questions about content performance and to build an internal dashboard. The data is not sold, not shared with third parties, not used for advertising, and not used to train AI models.

Storage

The sign-in token is stored only on the owner's own computer. Reports are kept on that computer as part of the owner's working files. Nothing is stored on a server run by Content Hub.

Google API Services User Data Policy

Content Hub's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the token file on the owner's computer also ends access.
